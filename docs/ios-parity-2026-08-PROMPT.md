YOUR TASK THIS SESSION: the first true blocker only —
"Photos actually loading (signed media reads)".

Every photo and video in this app 403s once the media server enforces auth. The server
can require a signed token on each /f read; the web client attaches one, iOS does not.
Enforcement is currently held at MEDIA_AUTH=report specifically so iOS keeps working, so
this is what unblocks turning real link-sharing protection back on for the family.

Complete, working Swift for it is in §0 of docs/ios-parity-2026-08.md — a MediaToken
actor, an @Observable store, and host-based URL signing. Adapt it to this project's
conventions rather than pasting it blind.

RULES — these come from real incidents on the web side:
